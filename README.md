# LUX — Language Uncertainty Extractor\n\n## Project Overview\n**LUX (Language Uncertainty Extractor)** is a research project focused on **pre-generation hallucination-risk prediction** for open-weight Large Language Models (LLMs).\n\n### Research Title\nPre-Generation LLM Hallucination Risk Prediction\n\n### Research Question\n> "Can combining observable prompt-level features with the target LLM's internal pre-generation hidden representations improve hallucination-risk prediction compared with using either information source alone?"\n\n---\n\n## Key Principles & Architectural Constraints\n- **Research Project**: This repository follows a strict, principled research methodology.\n- **Pre-Generation Prediction**: Risk assessment occurs *before* the target LLM generates its answer.\n- **Frozen Target LLM**: The target model (Qwen3 family) remains frozen and is not fine-tuned.\n- **Separate Predictor**: The hallucination risk predictor is a separate model from the target LLM.\n- **Feature Fusion**: Predictor inputs combine observable prompt-level features and internal pre-generation hidden representations from the target LLM.\n- **Strict Leakage Prevention**: Generated answers are **NEVER** used as predictor features. They are strictly reserved for constructing the empirical ground-truth target during training.\n\n---\n\n## Phase 0 Status: COMPLETE\n\nPhase 0 established the complete dataset infrastructure, data
